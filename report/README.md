# Report scaffold

Use the supplied, unchanged `aaai24.sty` and `aaai24.bst` from the camera-ready LaTeX directory of `AuthorKit24-2.zip`. Their existing notices remain intact. The course adopts the layout; conference submission, copyright-transfer and release-form instructions are not course deliverables.

Maximum body length: six pages, excluding references. Use an author-visible report after verifying all five formal names. No report text or experimental result is fabricated here.

Suggested space allocation, to revise around actual evidence:

1. Problem, question and supported contributions.
2. Exact SimpleNet mechanism and closest related work.
3. Paired relighting, score objective and implementation details.
4. Data, split/lighting protocol, selection and compute.
5. Main results, augmentation control and ablations.
6. Failures, efficiency, limitations and conclusion.

Include a method figure, quantitative regular/changed-light comparison, and aligned input/heatmap examples. Each visual needs a specific claim. Explain the relevant invariance-versus-defect-sensitivity tradeoff without listing unrelated lecture topics.

Before submission, build with the original layout, inspect every rendered page, check the six-page body limit and trace every number to a recorded run. For the five-minute video, explain the problem, mechanism, main evidence and limitations as one coherent argument.
