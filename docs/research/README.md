For each claim, record a direct source and page/section, what was actually observed, its limitation, and the implication for this proposal. Distinguish paper-reported evidence from our measurements. Link code, configs and artifacts for experiments. Negative results count when the experiment and conclusion are sound.

Shared starting points:

- [SimpleNet paper](https://arxiv.org/abs/2303.15140) and [pinned code](../../third_party/SimpleNet).
- [AD 2 protocol](https://arxiv.org/html/2503.21622v1) and [current dataset resources](https://www.mvtec.com/research-teaching/datasets/mvtec-ad-2).
- [PIAD, CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Yang_PIAD_Pose_and_Illumination_agnostic_Anomaly_Detection_CVPR_2025_paper.html): illumination robustness predates this project; distinguish its pose/3D setting from ours.
- [Unsupervised industrial anomaly detection using paired well-lit and low-light images, JCDE 2025](https://academic.oup.com/jcde/article/12/5/41/8119431): directly relevant paired-lighting work, including synthetic gamma variants. Inspect its objective and architecture before claiming a new integration.

This starting list is not an exhaustive novelty search.
