# Run evidence

Generated results are ignored. Use one directory per dataset/category/variant/seed/run ID. Save the artifacts specified in [the protocol](../docs/protocol.md#cost-and-evidence), including configs, hashes, raw scores, checkpoints, logs, calibrated thresholds, maps and runtime measurements.

The [bottle baseline development results](../docs/baseline-results.md) contain a provenance-checked compact table and links to evaluation artifacts stored outside Git. No test accuracy is claimed. Keep reviewed compact tables in `docs/`; do not fill them with guessed values, historical benchmark scores or synthetic smoke outputs.
